# Historical audit record — seven S24 figure-input tables

**Publication restriction (17 November 2026):** The seven processed CSV datasets referenced by this audit have been removed from the public GitHub branch at the researcher's request. This document describes checks on local research files; it does not mean those files are included or available for download.

The local audit checked structural coverage, years, region and soil-class keys, water-deficit summary consistency, figure-input formats, and relationships between yield units. The S24 figure-generation workflow was also locally tested. These checks did not recompute the sequential water balance or independently reproduce the upstream raster calculations.

The public `scripts/generate_manuscript_figures.ipynb` is retained for code review. To reproduce its figures, authorized researchers must supply the seven input CSV datasets separately. Do not treat the public repository as a complete reproducibility package.
