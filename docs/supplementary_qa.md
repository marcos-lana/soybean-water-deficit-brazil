# TS01 / TS02 — Audit record

## Source / reference
- `data/sources/ts01_spatial_intersections_original.csv` (original export: `25_TS01_resumo_espacial_v4.csv`): 17 rows, 11 fields, generated by the vector intersection step in S25 v4 as supplied by the researcher; metadata: `Criterio_intersecao=vetorial_UF`, `Area_min_intersecao_ha=1`.
- `TS02_soybean_planted_area_summary_2014_2023.csv`: 17 UF rows, annual planted area from 2014–2023 plus mean, minimum and maximum, derived from IBGE/SIDRA PAM Table 5457 as documented in the prior TS02 audit.
- Manuscript control: `Tables.docx`, Table TS01 and Table TS02, provided by the researcher.

## Checks performed
1. **Completeness:** 17 UF codes in both CSVs; no duplicated UF codes.
2. **TS01 manuscript equivalence:** 17/17 UFs matched exactly for region identifiers (MRS and REC), translated biome lists, collection windows, UF names and planted-area ranges, after the documented editorial transformation.
3. **Temporal scope:** TS02 has 2014–2023 (10 distinct years).
4. **Area range calculation:** minimum/maximum computed from the ten TS02 annual values for each UF; numerical area range formatted as 10³ ha with one decimal place.
5. **DF:** `MRS_n=0`, `REC_n=0`, blank codes in original; rendered as `—` in the publication table.
6. **BA:** original `Biomas_n=4` with `Ilhas Oceânicas`; processed data list three biomes after explicit editorial exclusion. Original source remains unchanged.
7. **Script 25 execution:** not re-executed in this package audit. The supplied output was used and the transformation was reproduced locally. Only the GEE export task description, output filename, and associated notebook documentation were renamed; processing logic was not modified.

## Scientific interpretation limits
- Vector polygon intersections identify regional and biome units crossing UF boundaries, not the fraction of soybean pixels in each unit.
- TS02 contains **planted area**, not harvested area, yield or raster-classified soybean area. Do not conflate these denominators.
- Public release of S25 does not imply unrestricted access to the referenced private GEE assets. Documentation must state the asset accessibility policy.
